# TechMarket

**TechMarket** — навчальний проєкт інтернет-магазину електроніки, створений за мотивами популярних онлайн-магазинів, зокрема Rozetka.

## Про проєкт

Сайт демонструє каталог електроніки та сучасних гаджетів. Має простий і зрозумілий інтерфейс, адаптивний дизайн і картки товарів із зображеннями та цінами.

## Основні можливості

- Головна сторінка з рекламним банером.
- Пошуковий рядок.
- Навігація за розділами.
- Популярні категорії товарів.
- Каталог популярних товарів.
- Зображення товарів.
- Кнопки додавання товарів до кошика (демонстраційні).
- Адаптивне відображення на різних пристроях.

## Використані технології

- HTML5
- CSS3
- Bootstrap 5
- jQuery
